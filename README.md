🏎️ NEON OVERDRIVE

Neon Overdrive is a high-speed, 3D endless synthwave racing game built from scratch using React, TypeScript, and HTML5 Canvas.

Navigate futuristic neon highways, dodge high-speed traffic, push your limits with Nitro boosts, collect coins, and unlock customizable vehicle skins in the garage!

✨ Features
Retro Synthwave Aesthetics: Dynamic color-cycling environments, audio-reactive visual effects, particle bursts, and camera shake.

Garage & Shop System: Earn coins during races to purchase, unlock, and equip custom car skins.

Power-Ups & Collectibles:

🪙 Coins: Earn currency to spend in the shop.

🛡️ Shields: Protect your car from fatal crashes and wipeouts.

⚡ Nitro Orbs: Charge your boost meter to smash through oncoming traffic at breakneck speeds.

Dynamic Gameplay:

Beat the clock by reaching stage Checkpoints for bonus time.

Chain near-misses and high speeds to raise your Score Multiplier.

Dynamic difficulty scaling across multiple unique zones.

High Score Leaderboard: Local persistent storage saves your high scores, best combos, and statistics.

Cross-Platform Controls: Full support for Keyboard, Touch/Mobile gestures, and Gamepads.

🕹️ Controls
Action                    Keyboard                 Touch / Mobile

Steer Left / Right	      ← → or A D	          Hold Left / Right Side
Brake	                   ↓ or S	              Hold Both Sides
Nitro Boost	              Space or ↑	          Tap Nitro Button / Swipe Up
Pause	                   P or Esc	              Pause Icon
Mute Sound	                  M	                  Sound Icon

🛠️ Built With
Frontend Framework: React + Vite

Language: TypeScript

Graphics: HTML5 2D Canvas (Custom Pseudo-3D Projection Engine)

Audio: Web Audio API (Synthesized SFX & Audio Engine)

Storage: Web Storage API (localStorage for currency, unlocked skins, & scores)

🚀 How to Run Locally
1. Clone the repository:

git clone https://github.com/RusiruWimukthiWilson/neon-overdrive.git
cd neon-overdrive

2. Install dependencies:

Bash
npm install

3. Start the development server:

Bash
npm run dev

4. Open your browser and navigate to http://localhost:5173.
